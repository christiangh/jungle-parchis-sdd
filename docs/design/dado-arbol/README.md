# Dado

Las seis caras del dado: madera con puntos de arbusto. Exportado de Claude Design.

- `svg/dado-cara-1.svg` … `dado-cara-6.svg`: fuente, en vectorial. Es lo que usa la aplicación, sin los metadatos de exportación.
- `png/dado-cara-1.png` … `dado-cara-6.png`: las mismas caras en 1024 × 1024, como vista previa.

El dado se coloca sobre el tronco del centro del tablero. El giro al tirar se hace en código y respeta `prefers-reduced-motion`.
