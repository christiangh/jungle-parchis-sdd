# Avisos

Cartel de madera pintada del color del jugador, con un círculo de su color y el texto del aviso. Exportado de Claude Design.

- `alerta-tablon.png`: ejemplos de «Turno de Rojo» y «Turno de Amarillo».

Es el patrón de todos los avisos de la partida: el turno de cada color y los avisos de tirada perdida, repetir con un 6, tres seises y premio pendiente. La aplicación lo reconstruye con la paleta del tablero, no con la imagen.
